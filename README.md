# 🐾 PromptCat 

这是一个基于 **Electron** 和 **WebGL (GLSL 着色器)** 深度定制的极轻量桌面交互宠物。

它不仅仅是一个用于解压的视觉挂件，更是一个融合了**Getting Things Done)理念**、习惯打卡与健康关怀系的个人数据中心。它的底层没有使用任何一张静态图片，所有毛发、斑纹与动作均由纯粹的数学公式（SDF 有向距离场）实时演算生成。

---

✨ 核心特性 

### 🎨 1. 数学之美 

- **无损缩放**：采用 WebGL 物理像素渲染，无论使用鼠标滚轮将其缩小至硬币大小，还是放大至半个屏幕，边缘永远保持视网膜级  的极致平滑。
- **基因刷新**：每次双击或单击唤醒，小猫的毛色、斑点、花纹都会通过哈希随机种子（Seed）重新生成。

### 🧠 2. 无感收纳

- **双模切换**：对准小猫**双击鼠标左键**，即可在“🌲 长期树林（提示词库）”与“☀️ 今日暂存（临时待办）”两种胃口模式间无缝切换。
- **极速录入**：选中任何文本按下 `Ctrl + V`，或直接拖拽文本到小猫身上，系统会根据当前的状态机模式，自动将数据路由至对应的底层数据库。

### ✅ 3. 三维数据看板 (GTD 闭环)

右键点击小猫唤出收纳库面板，包含三大独立模块，支持全生命周期管理（CRUD）：

- **☀️ 今日暂存**：记录稍后阅读、临时灵感或日内待办。点击完成划线，跨日系统自动清空，保持大脑极简。
- **🗓️ 固定事项**：每日习惯打卡（如：吃维生素、喝几杯水等）。
- **🌲 长期树林**：沉淀优秀的 AI 提示词或长期代码片段，点击卡片一键复制。

### 🩺 4. 私人健康提醒)

后台静默运行的 Cron Jobs 守护进程，全面接管你的桌面健康：

- **💧 饮水提醒**：每 90 分钟自动弹出气泡与系统通知，提醒补充水分。
- **🧘 拉伸提醒**：每 45 分钟提醒你离开屏幕，活动筋骨。
- **⏰ 习惯智能轮询**：每 1 小时检查一次“固定事项”库，如果发现有未勾选的习惯，小猫会精准报出任务名称提醒你完成。

## 🎮 操作指南 

| 交互动作 | 触发效果 |

| :--- | :--- |

| **按住鼠标左键拖拽** | 在桌面上自由移动小猫 |

| **鼠标滚轮上下滚动** | 以小猫为中心，进行丝滑的无级放大/缩小 |

| **鼠标左键双击** | 切换小猫的收纳模式（长期库 ↔ 今日待办），并刷新基因 |

| **鼠标右键单击** | 打开数据收纳库面板 |

| **Ctrl + V / 拖拽文本** | 触发吞咽特效，极速收纳文本至当前模式的数据库 |

## 🚀 开发者指南 (Installation & Build)

### 1. 环境准备

确保你的电脑已安装 [Node.js]([https://nodejs.org/)。]([https://nodejs.org/)。](https://nodejs.org/)。))

### 2. 本地运行

克隆本仓库后，在终端执行以下命令：

```bash

# 安装底层依赖

npm install

# 启动小猫

npm start
```
